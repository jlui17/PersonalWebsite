Sprites

The people (and dog, and robots) of justinlui.dev

Pixel sprites exported from the site's sheets as plain SVG. Each action is shown at true size and at 4×. Animated files switch frames with a CSS animation inside the SVG, so an <img> plays them. Place them at true size or a whole-number multiple, never in between, feet on a hairline rule. See README.md for the rules.
